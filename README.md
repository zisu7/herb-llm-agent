# 基于LLM多智能体的中药天然产物研发 + 药膳智能养生辅助系统

## ⭐ 设计亮点：双模块 + 双入口架构

本项目创新性地采用**双模块、双入口**设计，一套代码同时覆盖「中药天然产物研发」与「药膳智能养生」两大应用场景，兼顾科研探索与落地实用：

## 项目简介

本项目分为两大核心模块：

### 模块一：中药天然产物研发模块（科研方向 · 模拟AI制药、天然产物研发）
基于828味本地中药材数据集（按《中药学》十四五第五版标准分类整理，覆盖23大类），提供以下科研级数据查询与分析能力：
- 浏览全部药材数据（名称、类别、归经、功效、活性成分、用量）
- 药名关键词精准检索 + 模糊匹配
- 按中药类别（清热药/补虚药/温里药/理气药等23大类）筛选
- 按归经条件（心肝脾肺肾等十二经）智能筛选
- 数据统计功能（药材总量、各类别计数）
- 药食同源药材清单独立查询

### 模块二：三智能体药膳问诊模块（养生方向 · 药食同源落地）
基于大语言模型多Agent流水线架构，实现多轮问诊到食疗方案的完整闭环：
- **Agent1 体质辨证**：接收用户多轮身体症状描述，严格依据《中医体质分类与判定》九种体质标准自动辨证，输出核心体质+兼夹体质、推理依据，并强制附带养生免责声明
- **Agent2 药材匹配**：结合辨证结果与本地药材库，筛选适配养生药材（优先选用药食同源品种），每味标注性味归经、日常用量、适配理由，并提炼一组3～5味简易代茶饮方案
- **Agent3 食疗方案**：基于辨证与药材，生成两套食补方案（汤/粥/茶饮轮换），包含配方表、家庭烹饪详细步骤（预处理/火候/时长）、食用指导（频次/最佳时间/持续周期）、禁忌与注意事项

> 重要说明：本项目仅做养生科普参考，不能替代执业医师诊断与治疗，不具备行医功能。

## 运行方式（双入口 · 双场景）

对应上面两大模块，系统提供**两套独立启动入口**，并按用户是否已知自身体质划分为**两种使用场景**，按需选择即可：

---

### 🎯 场景一：用户已知自身体质（无需问诊，直接出方案）

> 适用情况：你已经清楚自己属于九种体质中的哪一种（如气虚质、阳虚质等），只想快速拿到对应的药膳、药茶推荐。

**入口**：`herb-llm-agent` 目录下的 `main.py`

**执行位置**：进入 `herb-llm-agent` 文件夹

```bash
python main.py
```

启动后展示主菜单，输入数字 **7**，再根据提示输入体质序号（1-8），即可直接生成药膳、药茶推荐方案与配伍禁忌提醒，**无需多轮问诊**：
```
7.输入体质生成药膳、药茶推荐方案，附带配伍禁忌提醒
  1.气虚质  2.阳虚质  3.阴虚质  4.痰湿质
  5.湿热质  6.血瘀质  7.气郁质  8.特禀质
请输入体质序号(1-8):
```

---

### 🎯 场景二：用户不清楚自身体质（需先问诊辨证）

> 适用情况：你不确定自己的体质类型，希望系统通过多轮问诊 + 三智能体自动辨证后再给出个性化食疗方案。

此场景提供**两种问诊入口**，任选其一：

#### 🚪 问诊入口 A：外层 `main.py` 菜单选 7（完整演示 + 问诊）

**适用**：想同时体验中药研发 + 药膳养生两大模块，体验完整菜单导航后再进入问诊

**执行位置**：项目外层根目录（包含 `herb-llm-agent` 文件夹的目录）

```bash
python main.py
```

主菜单中输入数字 **7** 即进入三智能体药膳问诊流水线：
```
【模块一：中药天然产物研发模块】
  1. 浏览全部药材数据    2. 药名关键词检索   3. 按中药类别筛选
  4. 按归经条件筛选      5. 数据统计功能
【模块二：药膳智能养生辅助模块】
  6. 查看全部药食同源药材清单
  7. 问诊系统（生成药膳、药茶推荐方案，附带配伍禁忌提醒）← 三智能体问诊入口
  0. 退出系统
```

#### 🚪 问诊入口 B：`python tests/test_interactive_food.py` 单独问诊（跳过主菜单）

**适用**：只想体验问诊功能、跳过主菜单、快速调试三段式 Agent 流水线、迭代优化提示词

**执行位置**：`herb-llm-agent` 目录下

```bash
python tests/test_interactive_food.py
```

启动后直接进入问诊对话，无需通过主菜单导航，直接运行三智能体链式流程：
1. 输入身体感受（支持多轮追问补全信息，输入 `exit` 退出）
2. Agent1 自动辨证 → Agent2 匹配药材+代茶饮 → Agent3 输出食疗方案

> 💡 **入口选择小贴士**：两个问诊入口（A 和 B）底层复用同一套 `src/agents` 三智能体提示词与 `food_pipeline.py` 流水线，问诊效果一致；区别仅在于 A 会先展示完整双模块主菜单，B 直接进入问诊对话。
