# herb‑llm‑agent｜中药多智能体AI系统
> 📌 中医药垂直领域开源AI项目｜双智能体模块可独立/联动运行｜仅供学习科研与养生参考，不构成医疗建议

## 📖 项目简介
本项目为个人独立开发的大模型多智能体面试作品集，结合中医药专业知识与大模型应用技术完成开发。

整套系统包含两套可独立运行，也可互相联动的智能Agent：
1. **中药天然产物研发 Agent**
面向中药相关专业本科生、研究生、科研爱好者，作为课题辅助底座。
内置828味中药材，素材参考中国中医药出版社《中药学》第五版，可用于药材信息速查、科研思路辅助。开发者可基于本项目继续整理药材资料、搭建研究工作流，根据自身课题方向二次定制拓展。后续迭代会完善成分‑功效对照表、药材混用风险提示等模块。

2. **药膳问诊 Agent2**
针对当代人群普遍忽视日常身体调理的现状，依托中医药传统思想实现食疗养生参考能力。
**仅依据中医八大体质做体质倾向判断，不做具体病症分析，不诊断疾病**。
- 用户清楚自己体质：在根目录`main.py`选择对应功能，直接输入体质，即可输出药膳、药茶推荐方案，附带配伍禁忌、慎用人群。
- 用户不清楚自身体质：在根目录`main.py`选择问诊流程，完成信息采集，给出体质倾向参考与食疗方案。

> ⚠️重要免责声明：本项目全部输出仅为中医药文化、科研、养生参考，**不能替代执业中医师线下诊疗**，身体存在疾病请及时前往正规医疗机构就诊。

## 🛠️ 技术栈
- Python
- Large Language Model（DeepSeek API）
- 多Agent任务分工设计
- 本地药材知识库约束，缓解大模型幻觉

## 🧩 两大智能体分工
1. **中药天然产物研发Agent**：药材检索、成分‑功效整理、配伍风险筛查、课题思路辅助、科研工作流梳理，面向中药科研学习场景。
2. **药膳问诊Agent**：模拟中医问诊流程，采集体质信息，输出药膳、药茶食疗方案，附带配伍禁忌提醒，输出内容做合规校验，过滤疾病诊疗类输出，补充免责提示。

## 🚀 运行说明
### 环境准备
1. 安装项目依赖
2. 在项目根目录配置 `.env` 文件，填入你的大模型API‑KEY，**请勿将密钥上传至仓库**。

## 📥 项目获取方式
### 方式1：Git克隆（推荐，方便后续拉取更新）

git clone https://github.com/zisu7/herb-llm-agent.git
cd herb-llm-agent
### 方式2：下载压缩包（无需Git工具）
 
1. 打开本项目GitHub仓库主页

2. 点击右上角绿色  <> Code  按钮

3. 选择  Download ZIP ，下载完整项目压缩包

4. 将压缩包解压到本地文件夹，进入项目根目录执行后续环境安装
 
💡重要提示
 

- 解压完成后，务必进入项目根目录（herb‑llm‑agent）再执行 python main.py ，否则会出现文件路径报错。

- 不要嵌套多层文件夹，避免出现 herb‑llm‑agent/herb‑llm‑agent 双层目录结构。

### 程序入口
所有功能统一在项目根目录 `main.py` 启动：

python main.py
主菜单输入对应数字，进入对应Agent流水线：
 
- 中药天然产物研发 Agent｜选项 1‑5

- 1.浏览全部药材数据

- 2.药名关键词检索

- 3.按中药类别筛选

- 4.按归经条件筛选

- 5.数据统计功能

- 药膳问诊 Agent｜选项 7‑8

- 7.问诊系统（完整多轮问诊，生成药膳、药茶推荐方案，附带配伍禁忌提醒）←三智能体问诊入口

- 8.输入已知体质，直接输出药膳药茶方案

- 9.退出系统
 
全部能力集中在根目录 main.py ，无需切换其他文件。

调试专用入口（跳过主菜单，用于快速迭代问诊流水线）
python tests/test_interactive_food.py
适用：只想体验问诊功能、跳过主菜单、快速调试三段式Agent流水线、迭代优化提示词。
